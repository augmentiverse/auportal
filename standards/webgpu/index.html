Overview

WebGPU exposes GPU resources, command submission and compute capabilities. It serves a different layer from spatial tracking and is not a substitute for WebXR.

Responsible organisation
W3C GPU for the Web Working Group
Publication status
Candidate Recommendation Draft
Version / snapshot
20 August 2026 snapshot

Role in the Augmentiverse

It can support advanced rendering and compute workloads where the platform supports the required capabilities. Integration with immersive presentation must be checked separately.

Where it is useful

  • GPU compute and inference
  • Complex 3D visualisation
Explore application contexts →

Limits and implementation choices

  • A draft standard with capabilities that depend on the platform.
  • WebGPU availability does not imply WebXR compatibility.
